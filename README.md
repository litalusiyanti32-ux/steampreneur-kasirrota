# KASIR BISA

**KASIR BISA** adalah proyek aplikasi kasir yang dikembangkan untuk membantu pelaku usaha kecil dan UMKM melakukan pencatatan transaksi dengan alur yang sederhana.

## Tujuan Proyek

Mengembangkan solusi kasir yang mudah dipahami dan digunakan, terutama oleh pelaku usaha yang membutuhkan proses transaksi praktis.

## Fokus Pengembangan

- Pencatatan produk dan stok.
- Pemindaian barcode untuk membantu proses transaksi.
- Keranjang belanja, pembayaran, dan perhitungan kembalian.
- Pencatatan serta rekap transaksi.
- Pengembangan fitur pendukung usaha secara bertahap.

## Status Proyek

Proyek sedang dalam tahap pengembangan dan pengujian. Ketersediaan serta kesiapan setiap fitur akan didokumentasikan sesuai hasil implementasi dan pengujian.

## Konteks Pengembangan

Proyek ini dikembangkan sebagai bagian dari challenge STEAMpreneur 2026.

## Teknologi

- Flutter
- Dart

## Catatan

Repositori ini digunakan untuk mendokumentasikan proses pengembangan, pengujian, evaluasi, dan perbaikan KASIR BISA.
